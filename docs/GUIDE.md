# 咪咪 使用指南

## 1. 打开应用

打开应用，双击目录进入；双击文件使用系统默认应用打开。

## 2. 点击侧栏箭头展开目录；使用路径栏和前进、后退按钮导航。

点击侧栏箭头展开目录；使用路径栏和前进、后退按钮导航。

## 3. 在列表表头选择排序；搜索框筛选当前目录

在列表表头选择排序；搜索框筛选当前目录，不能代替全盘搜索。

## 4. 通过“显示 → 双列浏览”或 ⌘⇧D 开启双列。点击某一列后

通过“显示 → 双列浏览”或 ⌘⇧D 开启双列。点击某一列后，顶部工具栏和搜索操作该列。

## 5. 在两列之间拖放文件

在两列之间拖放文件，或拖到目标目录；确认目标位置后松开。

## 6. 通过“显示 → 自定义工具栏”调整按钮；拖动收藏夹项目管理常用路径。

通过“显示 → 自定义工具栏”调整按钮；拖动收藏夹项目管理常用路径。

## 操作边界

- 当前不提供网络连接功能。
- 缩略图依赖 macOS Quick Look；部分视频可能无法生成预览。
- FFmpeg 取帧为可选后备，本应用未打包 FFmpeg。
- 部分 Finder 操作可能需要自动化授权；文件操作仍受磁盘权限约束。
- 属于个人维护版本，尚未完成全面鼠标键盘验收，不承诺覆盖所有文件系统。
